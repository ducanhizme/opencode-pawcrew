# crew-code Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a DSH plugin `@crew-code/dsh-crew-code` that ports the opencode-crewkit agent roster (4 primaries + 5 subagent personas + superpowers fork + wiki tools) onto DeepSeek Harness's Cordis framework.

**Architecture:** Layered plugin family (Approach B): five plugins in one bundle. crew-core owns the superpowers bootstrap section + human commands; crew-skills serves vendored superpowers skill markdown via DSH's ctx.skills; crew-skills-restrict shadows process skills for LetMeowCook/LoreCat; crew-subagents defines a custom `subagent` tool with per-call persona + continuable support; crew-wiki reimplements the six wiki_* deterministic tools on ctx.tools. Four agent presets ship as `agent.cordis.yml` composition dirs discovered via `config.roots`; presets mount plugin subsets to scope capabilities.

**Tech Stack:** TypeScript, Cordis (@deepseek-ai/cordis), DSH core packages (dsh-agent, dsh-agent-presets, dsh-skill, dsh-subagent, dsh-tools, dsh-fs), vitest, tsdown, git subtree (superpowers skills).

**Spec:** `.ai/superpowers/docs/specs/2026-08-17-crew-code-design.md`

## Refinements over the spec (resolved during planning)

The spec flagged three open questions; research against DSH source (commit `99f6f02f`) resolved them:

1. **`ctx.agentPresets` is filesystem-only.** No `register()` API. Presets are directories containing `agent.cordis.yml` (the composition file — NOT `composition.yml`), discovered from `config.roots`. So `crew-presets` does NOT programmatically register presets; it contributes a `config.roots` entry pointing at its bundled preset dirs. Source: `packages/preset/agent-presets/src/discovery.ts` (`COMPOSITION_FILE = 'agent.cordis.yml'`).

2. **The shipped `subagent` tool hides `persona`/`toolFilter`** — those are config-level only (`packages/subagent/tool-subagent/src/index.ts` L52-68). But `ctx.subagents.start()` accepts per-call `persona`/`toolFilter` (`SubagentStartRequest`, `packages/subagent/subagent/src/types.ts` L134-148). So `crew-subagents` defines a **custom** `subagent` tool that accepts `persona` and `continuable` as model-facing params and builds `SubagentStartRequest` itself.

3. **`send_message` / `interrupt_agent` / `list_agents` already ship** in `dsh-tool-subagent-control` (`packages/subagent/tool-subagent-control/src/index.ts` + `list-agents.ts`). crew-code REUSES these (mounts the shipped plugins in primary presets) instead of defining `subagent_followup`/`subagent_interrupt`/`subagent_list`. Only the custom `subagent` tool (with persona) is new.

Net effect on file layout:
- `src/presets/*/composition.yml` → `src/presets/*/agent.cordis.yml`
- `src/presets/index.ts` no longer "registers presets" — it just exists as a config-contributing plugin (or is removed; preset discovery is via `config.roots` in the bundle row).
- `src/subagents/` adds a `subagent.ts` (custom tool) and does NOT add followup/interrupt/list tools.

## Global Constraints

- Target: DSH `master` at commit `99f6f02f` (0.1.0-rc.7 era). DSH is developer-preview; pin peer deps to `workspace:*`.
- Composition file name: `agent.cordis.yml` (exact, from `COMPOSITION_FILE`).
- Preset id = directory name; must match `/^[a-z0-9]+(?:-[a-z0-9]+)*$/` (`PRESET_ID` regex in discovery.ts).
- Skill names: kebab-case `^[a-z0-9]+(?:-[a-z0-9]+)*$`.
- PromptSection orders: `-100` harness identity, `-90` crew superpowers directive, `0` persona, 100–199 tool guidance.
- Subagent toolFilter deny list: `['subagent','edit','write','patch']` for all crew subagent personas (subagents never spawn further agents; never write).
- All agent identity content ported from opencode-crewkit `.opencode/agent/*.md` with opencode frontmatter stripped and tool references rewritten to DSH vocabulary.
- Superpowers skill content vendored via git subtree at `vendor/superpowers/`; bootstrap body is forked once in `src/core/bootstrap.ts` and does NOT auto-update with subtree pulls.
- `pnpm test` and `pnpm test:e2e` must be green before v1 is done.
- Commit style: conventional commits (`feat:`, `test:`, `chore:`, `docs:`).

`src/core/commands.ts`:
```ts
import type { Context } from '@deepseek-ai/cordis'

interface CommandCallArgs {
  args: string
}

const PRESET_FOR_COMMAND: Record<string, string> = {
  '/build': 'pawbuilder',
  '/patch': 'patchpaw',
  '/cook': 'letmeowcook',
  '/lore-cat-save-it': 'lorecat',
}

async function route(
  ctx: Context,
  presetId: string,
  prompt: string,
): Promise<void> {
  // Create an agent scoped to this command, mount the preset, deliver the prompt.
  // The exact create/mount signature follows DSH's ctx.agents.create + ctx.agentPresets.mount.
  const ownerCtx = ctx // caller owns the lifecycle
  const handle = await (ctx as any).agents.create({
    // DSH CreateAgentOptions — minimal fresh session
    meta: {},
  })
  const agent = handle.agent ?? handle
  await (ctx as any).agentPresets.mount(agent.ctx, presetId)
  const promptText = prompt || `Execute the ${presetId} workflow for the current session context.`
  agent.followup({
    id: `cmd-${Date.now()}` as any,
    source: { kind: 'user' },
    content: [{ type: 'text', text: promptText }],
  })
}

export function registerCommands(ctx: Context): () => void {
  const disposes: Array<() => void> = []
  for (const [cmdName, presetId] of Object.entries(PRESET_FOR_COMMAND)) {
    const d = (ctx as any).commands.register({
      name: cmdName,
      async handler(call: CommandCallArgs) {
        await route(ctx, presetId, call.args)
      },
    })
    disposes.push(d)
  }
  return () => disposes.forEach((d) => d())
}
```

import { readdir, readFile, stat } from 'node:fs/promises'
import { join, dirname, basename } from 'node:path'
import { fileURLToPath } from 'node:url'

const __dirname = dirname(fileURLToPath(import.meta.url))

interface SkillCandidateMinimal {
  name: string
  description: string
  invocation: { modelInvocable: boolean; userInvocable: boolean }
  source: string
  provider: string
  rank: number
  path?: string
  locator: unknown
}

async function scanDir(root: string, providerName: string, source: string, rank: number, signal: AbortSignal): Promise<SkillCandidateMinimal[]> {
  const out: SkillCandidateMinimal[] = []
  let entries: string[]
  try {
    entries = await readdir(root, { withFileTypes: true })
  } catch {
    return out
  }
  for (const entry of entries) {
    if (signal.aborted) return out
    const dirPath = join(root, entry.name)
    // Directory bundle: <name>/SKILL.md
    if (entry.isDirectory()) {
      const skillFile = join(dirPath, 'SKILL.md')
      try {
        const s = await stat(skillFile)
        if (s.isFile()) {
          const body = await readFile(skillFile, 'utf8')
          const { description, invocation } = parseFrontmatter(body)
          out.push({
            name: entry.name,
            description,
            invocation,
            source,
            provider: providerName,
            rank,
            path: skillFile,
            locator: skillFile,
          })
        }
      } catch { /* skip */ }
    }
  }
  return out
}

function parseFrontmatter(body: string): { description: string; invocation: { modelInvocable: boolean; userInvocable: boolean } } {
  // Minimal frontmatter parse: look for description in YAML frontmatter.
  const fmMatch = body.match(/^---\n([\s\S]*?)\n---/)
  let description = ''
  let modelInvocable = true
  let userInvocable = true
  if (fmMatch) {
    const fm = fmMatch[1]
    const descMatch = fm.match(/^description:\s+(.+)$/m)
    if (descMatch) description = descMatch[1].trim().replace(/^["']|["']$/g, '')
    if (/disable-model-invocation:\s+true/m.test(fm)) modelInvocable = false
    if (/user-invocable:\s+false/m.test(fm)) userInvocable = false
  }
  return { description, invocation: { modelInvocable, userInvocable } }
}

export function createSkillProviders(ctx: Context): () => void {
  const disposes: Array<() => void> = []

  // Provider 1: vendored superpowers
  const superpowersRoot = join(__dirname, '../../vendor/superpowers/skills')
  disposes.push(
    (ctx as any).skills.registerProvider((control: any) => ({
      name: 'crew-superpowers',
      async list({ signal }: any) {
        const sig = signal ?? control.signal
        const candidates = await scanDir(superpowersRoot, 'crew-superpowers', 'bundled', 400, sig)
        return candidates.sort((a, b) => a.name.localeCompare(b.name))
      },
      async get(candidate: SkillCandidateMinimal) {
        const body = await readFile(candidate.path!, 'utf8')
        const content = body.replace(/^---\n[\s\S]*?\n---\n?/, '')
        return { ...candidate, content, resourceBase: { kind: 'directory', path: dirname(candidate.path!) } }
      },
    })),
  )

  // Provider 2: bundled project skills
  const projectRoot = join(__dirname, '../../skills')
  disposes.push(
    (ctx as any).skills.registerProvider((control: any) => ({
      name: 'crew-project-skills',
      async list({ signal }: any) {
        const sig = signal ?? control.signal
        const candidates = await scanDir(projectRoot, 'crew-project-skills', 'project-dsh', 100, sig)

}

import type { Context } from '@deepseek-ai/cordis'
import { CREW_SUBAGENTS } from './personas'

export function registerSubagentTool(ctx: Context): () => void {
  return (ctx as any).tools.register({
    name: 'subagent',
    description: 'Dispatch a crew-code subagent with a persona. One-shot (default) returns the final output; continuable returns a childId for follow-ups via send_message.',
    parameters: {
      description: { type: 'string', required: true, description: 'A short (3-5 word) description of the delegated task.' },
      prompt: { type: 'string', required: true, description: 'The full prompt for the subagent. Use the six-section format: TASK, EXPECTED OUTCOME, REQUIRED TOOLS, MUST DO, MUST NOT DO, CONTEXT.' },
      persona: {
        type: 'string',
        required: true,
        enum: Object.keys(CREW_SUBAGENTS),
        description: 'The subagent persona to dispatch.',
      },
      continuable: { type: 'boolean', required: false, description: 'If true, starts a continuable child and returns {childId, messageId}. If false (default), one-shot: returns the final output.' },
    },
    async execute(args: { description: string; prompt: string; persona: string; continuable?: boolean }, execCtx: any) {
      const spec = CREW_SUBAGENTS[args.persona]
      if (!spec) throw new Error(`unknown subagent persona: ${args.persona}`)
      const parent = (ctx as any).agents.requireInitiator()
      const content = [{ type: 'text', text: args.prompt }]
      if (args.continuable) {
        const { childId, messageId } = await (ctx as any).subagents.startContinuable({
          provider: 'spawn',
          label: args.description,
          prompt: content,
          parent,
          persona: spec.persona,
          toolFilter: spec.toolFilter,
          signal: execCtx?.signal ?? new AbortController().signal,
        })
        return { content: [{ type: 'text', text: `Continuable subagent started. childId=${childId} messageId=${messageId}. Use send_message to follow up.` }] }
      }
      const run = await (ctx as any).subagents.start({
        provider: 'spawn',
        label: args.description,
        prompt: content,
        parent,
        persona: spec.persona,
        toolFilter: spec.toolFilter,
        signal: execCtx?.signal ?? new AbortController().signal,
      })
      const result = await run.result
      try { await run.dispose() } catch {}
      const text = result.output.map((b: any) => b.text ?? '').join('\n')
      return { content: [{ type: 'text', text }] }
    },
  })
}

import { registerSubagentTool } from './subagent'
import { CREW_SUBAGENTS } from './personas'
import { registerRestrictor } from '../skills/restrict'
import { SUPERPOWERS_PROCESS_SKILLS } from '../skills/process-list'

const REVIEW_SKILLS = new Set(['requesting-code-review', 'receiving-code-review'])

function restrictProcessSkills(childCtx: any) {
  registerRestrictor(childCtx)
}

function restrictReviewOnlySkills(childCtx: any) {
  for (const name of SUPERPOWERS_PROCESS_SKILLS) {
    if (REVIEW_SKILLS.has(name)) continue
    (childCtx as any).skills.register({
      name,
      description: '',
      invocation: { modelInvocable: false, userInvocable: false },
      content: "This skill is not available in this agent's composition.",
    })
  }
}

function mountCrewWikiAndRestrict(childCtx: any) {
  restrictProcessSkills(childCtx)
  // Mount crew-wiki tools in the child scope. This re-runs crew-wiki's apply in the child context.
  // crew-wiki's index.ts exports apply; calling it with childCtx registers tools in that scope.
  import('../wiki/index').then(({ apply }) => apply(childCtx))
}

function resolveSetup(setupName: string): (childCtx: any) => void {
  switch (setupName) {
    case 'restrictProcessSkills': return restrictProcessSkills
    case 'restrictReviewOnlySkills': return restrictReviewOnlySkills
    case 'mountCrewWikiAndRestrict': return mountCrewWikiAndRestrict
    default: return () => {}
  }
}

export const name = 'crew-subagents'
export const inject = ['subagents', 'agents', 'tools']

export function apply(ctx: Context) {
  ctx.effect(() => registerSubagentTool(ctx))

  ctx.effect(() => (ctx as any).subagents.registerContinuableSetup((childCtx: any, info: { persona?: string }) => {
    const personaName = info.persona
    const spec = personaName ? CREW_SUBAGENTS[personaName] : undefined
    if (spec) resolveSetup(spec.setup.name)(childCtx)
  }))
}

import { existsSync } from 'node:fs'
import { join, dirname, resolve } from 'node:path'

/** Resolve the .ai/docs root from a starting cwd by walking up to the nearest .git. */
export async function resolveDocsRoot(fs: any, cwd: string): Promise<string> {
  // Walk up from cwd to find .git; .ai/docs lives at that root.
  let dir = resolve(cwd)
  while (true) {
    const gitDir = join(dir, '.git')
    if (await fs.exists(gitDir)) {
      return join(dir, '.ai/docs')
    }
    const parent = dirname(dir)
    if (parent === dir) break
    dir = parent
  }
  return join(cwd, '.ai/docs')
}

// Minimal YAML frontmatter parser (no dependency on js-yaml for simple key:value cases).
// For complex OKF frontmatter, use js-yaml if available; otherwise a hand parser for the subset we write.

export function parseFrontmatter(body: string): { frontmatter: Record<string, any>; content: string } {
  const m = body.match(/^---\r?\n([\s\S]*?)\r?\n---\r?\n?/)
  if (!m) return { frontmatter: {}, content: body }
  const fmRaw = m[1]
  const content = body.slice(m[0].length)
  const frontmatter = parseSimpleYaml(fmRaw)
  return { frontmatter, content }
}

function parseSimpleYaml(yaml: string): Record<string, any> {
  const out: Record<string, any> = {}
  for (const line of yaml.split('\n')) {
    const m = line.match(/^([a-zA-Z_][a-zA-Z0-9_]*):\s*(.*)$/)
    if (m) {
      const key = m[1]
      let val: any = m[2].trim()
      if (val.startsWith('"') && val.endsWith('"')) val = val.slice(1, -1)
      else if (val === 'true') val = true
      else if (val === 'false') val = false
      else if (/^-?\d+$/.test(val)) val = Number(val)
      out[key] = val
    }
  }
  return out
}

export function preserveUnknownFields(existing: Record<string, any>, incoming: Record<string, any>): Record<string, any> {
  const known = new Set(['title', 'date', 'status', 'type', 'x_wikiguy'])
  const result: Record<string, any> = { ...incoming }
  for (const [k, v] of Object.entries(existing)) {
    if (!known.has(k) && !(k in incoming)) result[k] = v
  }
  return result
}

export function serializeFrontmatter(fm: Record<string, any>): string {
  const lines: string[] = ['---']
  for (const [k, v] of Object.entries(fm)) {
    if (v && typeof v === 'object') {
      lines.push(`${k}:`)
      for (const [k2, v2] of Object.entries(v as any)) {
        lines.push(`  ${k2}: ${JSON.stringify(v2)}`)
      }
    } else {
      lines.push(`${k}: ${typeof v === 'string' ? JSON.stringify(v) : v}`)
    }
  }
  lines.push('---')
  return lines.join('\n')
}

export function createSearchTool() {
  return {
    name: 'wiki_search',
    description: 'Search ONLY the project knowledge corpus .ai/docs/** (specs, architecture, decisions/ADRs, workflows, references).',
    parameters: {
      query: { type: 'string', required: true, description: 'Search text (case-insensitive substring).' },
      kind: { type: 'string', enum: ['Specification', 'Architecture', 'Decision', 'Workflow', 'Reference'], required: false },
      limit: { type: 'number', required: false, description: 'Max matches (default 20).' },
    },
    async execute(args: { query: string; kind?: string; limit?: number }, execCtx: any) {
      const ctx = execCtx
      const root = await resolveDocsRoot(ctx.fs, ctx.session.cwd)
      const limit = args.limit ?? 20
      const entries = await ctx.fs.readDir(root)
      const results: Array<{ path: string; title: string; type: string; snippet: string }> = []
      const q = args.query.toLowerCase()
      for (const entry of entries) {
        if (!entry.endsWith('.md')) continue
        const full = `${root}/${entry}`
        const body = await ctx.fs.readFile(full)
        const { frontmatter, content } = parseFrontmatter(body)
        if (args.kind && frontmatter.type !== args.kind) continue
        if (content.toLowerCase().includes(q) || (frontmatter.title ?? '').toLowerCase().includes(q)) {
          const idx = content.toLowerCase().indexOf(q)
          const snippet = content.slice(Math.max(0, idx - 50), idx + 100)
          results.push({ path: full, title: frontmatter.title ?? entry, type: frontmatter.type ?? '', snippet })
        }
        if (results.length >= limit) break
      }
      const text = results.length === 0
        ? `No matches for "${args.query}" in .ai/docs.`
        : results.map((r) => `### ${r.title} (${r.type})\n${r.path}\n...${r.snippet}...`).join('\n\n')
      return { content: [{ type: 'text', text }] }
    },

export function createFreshnessTool() {
  return {
    name: 'wiki_freshness',
    description: 'Deterministic Git drift check for one .ai/docs document using its x_wikiguy metadata (verified_commit + covers). Returns LIKELY_FRESH, STALE_CANDIDATES, UNVERIFIED, UNKNOWN_COMMIT, or NO_GIT.',
    parameters: {
      path: { type: 'string', required: true, description: 'Document path inside .ai/docs.' },
    },
    async execute(args: { path: string }, execCtx: any) {
      const ctx = execCtx
      const root = await resolveDocsRoot(ctx.fs, ctx.session.cwd)
      const full = args.path.startsWith(root) ? args.path : `${root}/${args.path}`
      const body = await ctx.fs.readFile(full)
      const { frontmatter } = parseFrontmatter(body)
      const xw = frontmatter.x_wikiguy
      if (!xw || !xw.verified_commit) {
        return { content: [{ type: 'text', text: 'UNVERIFIED' }] }
      }
      // Run git log to check if covered paths changed since verified_commit.
      // Uses ctx.subprocess if available; fallback to a simple "NO_GIT" if not.
      const subprocess = (ctx as any).subprocess
      if (!subprocess) {
        return { content: [{ type: 'text', text: 'NO_GIT' }] }
      }
      const covers: string[] = xw.covers ?? []
      try {
        const out = await subprocess.exec(['git', 'log', '--name-only', '--oneline', `${xw.verified_commit}..HEAD`, '--', ...covers], { cwd: ctx.session.cwd })
        const changed = out.trim().length > 0
        return { content: [{ type: 'text', text: changed ? `STALE_CANDIDATES\n${out}` : 'LIKELY_FRESH' }] }
      } catch {
        return { content: [{ type: 'text', text: 'UNKNOWN_COMMIT' }] }
      }
    },
  }

    parameters: {

// crew-presets-config contributes a config root pointing at the bundled preset dirs.
// DSH's AgentPresets service reads config.roots and scans for agent.cordis.yml files.
// This plugin uses ctx.effect to register the root; the exact config contribution API
// is via the Config schema on the AgentPresets service — typically configured at the
// bundle row level. Here we ensure the bundled presets dir is in the roots.
export function apply(ctx: Context) {

  // We expose the path so the bundle/profile can reference it.
  // If DSH supports runtime root addition, use it; otherwise document the path in README.
  const presetsRoot = join(__dirname, '.')
  // Contribute via config: the bundle row for crew-presets-config can set
  // config.roots to include this path. This plugin is a marker; actual wiring
  // is in crew-code.yml / profile config.
  ctx.effect(() => {
    // If ctx.agentPresets exposes a runtime addRoot, call it.
    const anyCtx = ctx as any
    if (typeof anyCtx.agentPresets.addRoot === 'function') {
      return anyCtx.agentPresets.addRoot({ path: presetsRoot, trust: 'system' })
    }
    return () => {}
  })
}
