# /design

Route to **PawPixel**, the frontend and UI specialist.

Use for building, redesigning, or refining:
- Pages, components, layouts, flows
- Design systems and tokens
- Visual polish, motion, and responsive behavior
- Accessibility fixes and UI audits

## Examples

```text
/design a premium landing page for the Aura ERP launch
/design redesign the auth flow to feel more trustworthy
/design audit the dashboard for accessibility issues
/design add a responsive navigation shell to the existing app
/design polish the settings page — it looks generic
```

## What PawPixel does

1. Gathers design context (audience, use cases, brand tone, existing system).
2. Selects a taste direction from the available frontend taste skills.
3. Runs the `frontend-ui-engineering` skill plus the selected taste skill.
4. Builds within the existing project stack.
5. Verifies: render, keyboard, responsive, reduced-motion, loading/error/empty states.
6. Reports outcome with verification evidence.

## What PawPixel does NOT do

- Backend APIs, database schemas, auth logic
- Business-rule changes outside the UI layer
- Silent rewrites of production UI without approval

If backend support is needed, PawPixel will stop and ask whether to prototype with mocks or route to PawBuilder for end-to-end implementation.
