# Writing for Agents

Write instructions that make authority, execution, and completion explicit.

## Trigger

Use when creating or revising prompts, skills, specs, workflows, or other documentation an agent must execute.

## Procedure

1. Identify the reader, their authority boundary, and the task they must complete.
2. Put the decision-relevant context and non-negotiable constraints first.
3. Separate mandatory executable steps from reference material.
4. State inputs, outputs, failure modes, and observable completion evidence.
5. Point to one authoritative source for each rule; remove stale, duplicated, or contradictory instructions instead of adding another rule.
6. Use the existing procedure for the artifact type: Superpowers `writing-skills` for skill authoring, and LoreCat tools for durable `.ai/docs` knowledge.

## Boundaries

- This guides agent-facing documentation, not general product copy.
- It does not replace command routing, agent authority, or existing approval rules.
- Do not write `.ai/docs` directly; LoreCat owns that corpus.
