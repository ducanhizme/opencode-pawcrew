# Prototype

## Trigger

Use when one explicit question needs a throwaway experiment.

## Procedure

1. State the verification question and obtain the owning agent's required approval.
2. Create a visibly throwaway artifact outside `.ai/docs` and `.ai/superpowers` with in-memory data only.
3. Build only enough behavior to answer the question and record the observation.
4. Delete or archive the artifact after the answer; any production work returns to the normal approved flow.

## Boundaries

- Never create a Plan or Goal Record for a prototype.
- Never write durable knowledge directly; route reusable findings through LoreCat.
- Never promote a prototype to production implicitly; production work re-enters the owning agent's approved flow.
- PawPixel's UI mock workflow remains authoritative.
